# 使用说明

## 面试流程

1. 最多五个浏览器同时进入网站，各自填写面试官姓名，在设置确认名称、批次、评分项与权重。
2. 导入腾讯文档内容或 XLSX、CSV、TSV、ZIP，检查字段、重复报名和附件归属。
3. 来一位同学后搜索姓名，也能搜索班级、学号、电话、邮箱或原表内容。同名先核对班级、学号。
4. 打开报名详情。PDF 和图片直接预览，DOCX 下载查看。记录现场评价，可选评分。
5. 确认录用、候补或淘汰，还可标记待面试、面试中、缺席。名单支持筛选和批量处理。
6. 操作记录显示最近 100 条。可撤回记录在相关内容未被后续修改时允许撤回。
7. 名单菜单导出当前筛选结果 CSV，并下载 JSON 备份；附件另外下载。

## 评分

| 维度 | 权重 | 对应问题 |
| --- | --- | --- |
| 表达与自我认知 | 20% | 自我介绍 |
| AI 使用与实践 | 25% | 接触/使用过的 AI 模型 |
| 发展目标与匹配度 | 15% | 毕业方向，理想职位公司 |
| 入室规划与执行 | 25% | 加入工作室后的规划 |
| 参与意愿与时间安排 | 15% | 是否去其他工作室 |

每项 0–10 分，界面显示考察重点和分段参考。未提问项留空；全部当前维度已评分才计算百分制加权总分。改权重会重算总分；历史评分保留原维度，不转换成新维度。

多处报名本身不扣分，关注原因、时间和冲突处理。模型数量、付费订阅和理想公司名气不作评分依据。录用与淘汰始终由面试官确认。

## 协作

按浏览器身份计数，同浏览器多标签共用名额。不同浏览器、无痕窗口、设备可能占不同名额；这是容量控制，并非实名人数认证。

第六个浏览器等待，有空位自动尝试加入，也可从工具栏主动离开。每 15 秒续期；正常关页尝试释放，异常断线约 60 秒过期。断网或失去席位暂停写入，页面未保存输入保留。

不同报名可同时保存；同一报名若被他人先保存，拒绝过期输入并提示核对。请先记录自己的草稿，再打开最新资料。

## 备份与边界

- 网站公开、无需登录，所有访问者共用数据。面试官姓名仅是署名。
- 腾讯文档需复制/导出权限，未接入扫码授权和自动同步。
- JSON 包含报名、评分、配置与附件清单，不含附件文件，也不提供完整数据库与审计日志恢复。
- JSON 合并恢复每次最多 500 人，请求限制约 150 万字符；超过时不能直接一次恢复。非空库要求配置一致，否则从原数据导出 CSV 分批导入。
- 重复项跳过，同名不自动合并；格式与附件限制见[报名表格式](registration-format.md)。
- 没有 OCR、自动能力判断、自动录用、群消息、短信或邮件通知。
